# Security policy

This repository is a manuscript and its build configuration. It ships no
service, runs no server, and processes no user data.

## Reporting

Anything security-relevant in the build tooling belongs against
[content-kit](https://github.com/alpibrusl/content-kit/security), which is
where that code lives, or against
[cohort-kit](https://github.com/alpibrusl/cohort-kit/security) for the cohort
renderer. For anything in this repository, email **alfonso@alpibru.com** or open an
issue.

## If a secret scanner flags this repository

It will, and the finding is intended. `cohort/fixture/setup.sh` builds a
throwaway git repository for Session 3, and one of the things it plants there
is a Stripe-style key committed and then deleted in a later commit — so that
students can discover for themselves that deleting a secret from the working
tree does not remove it from the history.

The key is not a credential and never was. Its body spells out, in capitals,
that it exists only for training, and it is generated by a script rather than
copied from anywhere. The same is true of every other alarming-looking thing
under `cohort/fixture/`: an unauthenticated endpoint, a missing lockfile, a
runbook nobody has read. They are the exercise.
