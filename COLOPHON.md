# Colophon

This book is written in Markdown and built with
[content-kit](https://github.com/alpibrusl/content-kit), an open-source
toolchain for books-as-code. The manuscript lives in a repository with its
full history; a term-continuity linter checks that no word is used before it
is defined; and the same source renders to EPUB, HTML and PDF.

The concept ledger and continuity checker in this repository are working
prototypes of proposals filed against content-kit itself. If they land
upstream, this book's tooling gets simpler, not more locked in — which is
the point of building on something open.
