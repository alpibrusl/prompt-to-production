# The Prompt to... Series

Four short books, one underlying argument:

> AI gives you the capability. These books teach the judgement the capability assumes you already have.

For as long as building software, running an analysis, modelling a business's finances, or acting on a recommendation required real training, the training and the judgement came bundled together — you couldn't get one without absorbing the other along the way. An agent can now produce the visible output of all four without the training that used to guarantee the judgement came with it. Each book in this series exists to hand that judgement back on its own, deliberately, for one specific gap:

***Prompt to Production*** — software engineering discipline for people who can build software with an agent but are not software engineers. *You are reading this one.*

***Prompt to Evidence*** — analytical discipline for people who can perform sophisticated analysis with an agent but are not statisticians.

***Prompt to Ledger*** — financial discipline for people who can build financial models with an agent but are not accountants or finance professionals.

***Prompt to Decision*** — decision-making discipline for people who can get a well-argued recommendation from an agent but still have to decide whether to act on it.

The first three teach you to verify one kind of agent output before trusting it. The fourth is the layer above all three: even a trustworthy recommendation is not yet a decision, and that gap turns out to be this series' actual subject, the whole way through.

Same tooling, same discipline, a different gap each time. None of the four requires having read the others first — each stands on its own — but the argument underneath all four is the same one, and it gets a little clearer with each volume.
