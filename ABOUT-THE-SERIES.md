# The Prompt to... Series

Three short books, one underlying argument:

> AI gives you the capability. These books teach the judgement the capability assumes you already have.

For as long as building software, running an analysis, or modelling a business's finances required real training, the training and the judgement came bundled together — you couldn't get one without absorbing the other along the way. An agent can now produce the visible output of all three without the training that used to guarantee the judgement came with it. Each book in this series exists to hand that judgement back on its own, deliberately, for one specific gap:

***Prompt to Production*** — software engineering discipline for people who can build software with an agent but are not software engineers. *You are reading this one.*

***Prompt to Evidence*** — analytical discipline for people who can perform sophisticated analysis with an agent but are not statisticians.

***Prompt to Ledger*** — financial discipline for people who can build financial models with an agent but are not accountants or finance professionals.

Same tooling, same discipline, a different gap each time. None of the three requires having read the others first — each stands on its own — but the argument underneath all three is the same one, and it gets a little clearer with each volume.
